# Far Space

Космическая игра на Python с использованием библиотеки curses.

## Запуск

Игра тестировалась на Python версии 3.14. Клонируйте или скачайте данный репозиторий, перейдите в католог с игрой и запустите её через следующую команду:

```shell
python main.py
```
