# Far Space

Космическая игра на Python с использованием библиотеки curses.

## Особенности игры

- Нижняя панель показывает текущий год
- Под надписью года - подсказка, чем примечателен этот год
- Чем больше год, тем чаще летит мусор
- С 2020 года появляется пушка, можно сбивать мусор
- При столкновении с мусором - Game Over

## Запуск

Игра тестировалась на Python версии 3.14. Клонируйте или скачайте данный репозиторий, перейдите в каталог с игрой и запустите её через следующую команду:

```shell
python main.py
```

## Управление

- Стрелки — движение корабля
- Пробел — выстрел (появляется с 2020 года)
